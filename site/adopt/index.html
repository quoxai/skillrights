Make it automatic

Declaring rights on one skill takes a minute. These three integrations make it happen by default, for every skill you or your agents write. No account, no server, nothing phones home.

1. The agent skill#

A skill that licenses skills. Once installed, Claude (or any agent that reads the skills directory) applies a SkillRights declaration whenever it creates or publishes a skill: frontmatter field, licence text in LICENSES/, README line. It defaults to NoTrain and is bound by honesty rules: it will never present a declaration as a technical shield.

Install for Claude Code
git clone --depth 1 https://github.com/quoxai/skillrights /tmp/skillrights-install
cp -r /tmp/skillrights-install/integrations/claude-skill/skillrights ~/.claude/skills/
rm -rf /tmp/skillrights-install

The skill itself ships under SkillRights-Open-1.0: take it, adapt it, learn from it, training included.

2. Rules for CLAUDE.md / AGENTS.md#

If you would rather not install anything, paste this into your project's CLAUDE.md or AGENTS.md. Any agent working in the repo will then treat rights declarations as part of authoring a skill, not an afterthought.

CLAUDE.md / AGENTS.md snippet
### Skill licensing (SkillRights)
- When you create or substantially edit an agent skill, add a rights
  declaration: set `license: LicenseRef-SkillRights-NoTrain-1.0` in the
  SKILL.md frontmatter (unless the author chooses another variant), put the
  licence text in LICENSES/, and add the one-line header to the README.
  Licence texts and details: https://skillrights.org/
- Never remove or weaken an existing licence on a skill without the
  author's explicit instruction.
- Never describe a declaration as a technical block or a guaranteed legal
  shield. It is a dated statement of terms and non-consent; in the EU it
  supports a text-and-data-mining rights reservation.

3. The CLI in CI#

The skillrights CLI (zero dependencies, no telemetry, no network) validates that frontmatter, licence text and README agree. A GitHub Action wraps it, no npm install involved; it runs green on this project's own CI:

GitHub Actions step
- uses: actions/checkout@v4
- uses: quoxai/skillrights/action@master
  with:
    path: path/to/your-skill

Outside GitHub Actions, a checkout works anywhere node does:

Any CI (plain shell)
git clone --depth 1 https://github.com/quoxai/skillrights /tmp/sr
node /tmp/sr/cli/bin/skillrights.js check . || exit 1

An npm package (npx skillrights) is the next milestone; this page will update when it ships.

Suggested defaults. Professional expertise shared for use: NoTrain. Tutorials and community content meant to be learned from freely: Open. Private or commercial methodology: Reserved, behind gated access. Whatever you choose, the declaration costs about 20 tokens and only loads when the skill is invoked.
